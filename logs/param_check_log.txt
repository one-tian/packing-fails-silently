T 敏感性：结论会不会因为「数据上界取多少」而变
==============================================================================
  LPPMM-DA 用 160-bit 曲线阶。下表为所需位数（判定）随 T 的变化：

           n,w,k        T=10        T=50       T=100       T=500      T=1000      T=1500
  --------------------------------------------------------------------------------------
     (100, 5, 7)      115  ✓      128  ✓      134  ✓      149  ✓      155  ✓      158  ✓
     (500, 5, 5)      129  ✓      143  ✓      150  ✓      163  ✗      169  ✗      173  ✗
    (1000, 5, 7)      161  ✗      175  ✗      181  ✗      195  ✗      201  ✗      205  ✗
   (1000, 10, 3)      189  ✗      214  ✗      226  ✗      251  ✗      262  ✗      268  ✗

  ✓ = 可行，✗ = 不可行（诚实数据即绕回）
  读法：n=1000,w=5,k=7 在 T ≥ 100 时全部不可行 —— 结论不依赖 T 的精确取值；
        只有把 T 压到几十（远小于原文所述 500–1500 W 的量级）才勉强可行。

    1024   5             ≥1e6               ≥1e6

    1024  10             ≥1e6               ≥1e6

  读法一：LPPMM-DA 用 160-bit 曲线，k=7 时只能支持 135 台，
          而原文实验跑到 1000 台 —— 这正是 E4 判定的来源。
  读法二：超递增族（VPMDA/SA-MAD）在 160-bit、k=7 时 n=2 都不可行，
          即「根本上不了椭圆曲线」。这解释了 VPMDA 为何必须用 1024-bit Paillier——
          群的选择不是性能偏好，而是打包预算逼出来的。
