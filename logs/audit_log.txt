PART 1 · L1 密码体制层：平移元素是否存在（P1）
==============================================================================
  检验：对同一明文 m，构造 CT' = CT ⊞ τ(Δ)，看解密是否恰为 m+Δ

  Paillier (g=1+N)                 m=777 Δ=321 → Dec=777/1098  CT'≡Enc(m+Δ,r)=是  P1 成立
  BGN 型 (g^m·h^r)                  m=777 Δ=321 → Dec=777/1098  CT'≡Enc(m+Δ,r)=是  P1 成立
  EC-ElGamal (C1,C2)               m=777 Δ=321 → Dec=777/1098  CT'≡Enc(m+Δ,r)=是  P1 成立

  结论：三种体制的密文都形如 g^m·(随机化)，都允许公开计算 g^Δ。
        P1 不是 Paillier 的偶然性质，而是「加法同态 + 随机化因子与消息可分离」的直接推论。

PART 2 · L2 认证层：IA ⇏ AB（个体认证不蕴含聚合绑定）
==============================================================================
  同一个打包方案，换四种认证作用域，看攻击是否被拦。
  n=5, k=2, h=(1000,500)，数据 = [(523,112),(148,45),(907,203),(612,87),(355,61)]

  诚实结果：Σm = [2545, 508]，Σm² = [1618651, 67068]，剥离余项 = 0

  攻击：Δ = v₂·492 + v₄·132932 = 8313237277309583424
        目标：类型2 均值 200.00、方差 0.00

  [NONE              ] 验证通过 ← 攻击成功
      伪造密文解出 类型2: Σm=1000   均值=  200.00 方差=      0.00
  [INDIVIDUAL        ] 验证通过 ← 攻击成功
      伪造密文解出 类型2: Σm=1000   均值=  200.00 方差=      0.00
  [AGGREGATE_BY_AG   ] 验证通过 ← 攻击成功
      伪造密文解出 类型2: Σm=1000   均值=  200.00 方差=      0.00
  [MAC_BINDING       ] 验证失败 ← 已拦截
      伪造密文解出 类型2: Σm=1000   均值=  200.00 方差=      0.00（下行是伪造密文的解密值，说明攻击目标已达成，但验证层拒绝）

  ★ 关键一行：INDIVIDUAL 作用域下攻击照样通过。
    因为聚合签名承诺的是「每个 CT_i 没被改」，而不是「Π CT_i 等于什么」。
    这两个命题在代数上相互独立 —— IA（个体认证）不蕴含 AB（聚合绑定）。

PART 2B · 为什么「让聚合者签聚合结果」是循环论证
==============================================================================
  AGGREGATE_BY_AG 的验证为什么通过？因为签名人就是攻击者本人。
  任何由 AG 生成的、对 CT_agg 的承诺，AG 在篡改后都能重新生成 —— 它不构成约束。
  ⇒ 聚合绑定必须由**被聚合者共同**生成，不能委托给聚合者。这是修补设计的硬约束。

PART 3 · R1 修补：MAC 绑定实测
==============================================================================
  机制：每台 SM 额外发 τ_i = (k·Q_i + ρ_i) mod M，ρ_i 由 SM 与 CC 的 PRG 生成。
        CC 验 k·Q ≟ Στ_i − Σρ_i (mod M)。

  先看模数选择的影响（用真实密文检验，不是纸面推演）：
  mod r（配对群阶，41 bit）                   诚实=True  平移后明文改变=True  MAC通过=True  → 盲区可用 ← 危险
  mod N（Paillier 模数，512 bit）           诚实=True  平移后明文改变=False  MAC通过=True  → 平移无效

  ⇒ mod r 确实存在盲区：Δ = r 时明文改变、MAC 却照样通过。
     mod N 看似安全，但只是因为 Paillier 里 g^N ≡ 1 (mod N²)——
     换到 EC-ElGamal（群阶 r），任何 Δ 都是有效平移，mod r 就无遮拦。
     ⇒ MAC 的模数必须与「明文空间」一致，而不是随手取群阶。
  正式配置（mod N）：
  单点平移 Δ=v₂·100                → 拒绝 ← 已拦截
  完整伪造 Δ（均值200/方差0）            → 拒绝 ← 已拦截
  验证开销：1 次模乘 ≈ 0.3 μs（512 bit N）
  通信开销：每台 SM 多 1 个 |N| bit 标量 → 总计 +512n bit

  读法：前两列全中招 ⇒ 缺陷与密码体制无关，与打包方式也无关；
        第三列全中招 ⇒ 把承诺交给聚合者是循环论证；
        第四列全拦截 ⇒ 只有「被聚合者共同产生、聚合者无法伪造」的绑定才有效。

结论
==============================================================================
  [定理] P1 ∧ P2 ⇒ 普遍伪造。密码体制只决定平移元素的形式，不决定是否存在。
  [已实证] Paillier / BGN 型 / EC-ElGamal 三种体制的 P1 全部成立。
  [已实证] IA ⇏ AB：逐条认证（聚合签名/批量验证）挡不住聚合结果的篡改。
  [已实证] 聚合者自签无效：约束必须来自被聚合者。
  [已实证] R1（MAC 绑定）可拦截，但模数必须与明文空间匹配，否则存在模数盲区。

  总耗时 0.09s
