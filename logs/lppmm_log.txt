==============================================================================
 E5 · 两种打包原语的失效形态对照
==============================================================================
    VPMDA / SA-MAD：超递增序列 Σ b_i·m_i  → 越界 = 向高位进位
    LPPMM-DA      ：CRT 残差 a_t + b 块    → 越界 = (1) CRT 绕回 mod q_t
                                              (2) 向 b_{l+1} 块进位
    共同点：解码器的输出字母表由构造决定（余数 < 模数、计数 ≤ n），
            因此『恢复结果越界』这个信号在代数上不可用。

 结论
==============================================================================
  [A 级] LPPMM-DA 的 DC 侧验证 = GW 对 C 的自签名（Kgw 含 C，签名人是 GW）
         → 落入 AGGREGATE_BY_AG，攻击者改 C 后重签即通过，无需任何秘密
  [A 级] 原文『Data Integrity』段引用式 (14)（聚合公式）作为验证依据，
         而式 (14) 是 C = Σcj mod q —— 不构成对 C 的独立检查
  [A 级] 上报值超出 [0,T) 时，CRT 残差静默绕回，维度总和失真而人数可能仍正确
         → 空位 B 在第二种打包原语上复现，普遍性论证闭环
